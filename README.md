# 🛒 GroceryGo – Hyperlocal Grocery Ordering and Delivery Tracking Portal

## 📌 Project Overview

GroceryGo is a Laravel-based web application developed as an MCA Final Year Project. The system allows users to browse grocery products, add them to a cart, place orders, and manage purchases through a simple and user-friendly interface.

---

## 🚀 Features

- User Registration & Login
- Dashboard
- Product Management (CRUD)
- Category Management (CRUD)
- Product Search
- Shopping Cart
- Checkout System
- Order Placement
- Order History
- Admin Order Management
- Order Status Update

## ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/ashu12-ak/GroceryGo.git
```

Open Project

```bash
cd GroceryGo
```

Install Dependencies

```bash
composer install
```

Copy Environment File

```bash
cp .env.example .env
```

Generate Application Key

```bash
php artisan key:generate
```

Configure Database

Update your **.env**

```env
DB_DATABASE=grocerygo
DB_USERNAME=root
DB_PASSWORD=
```

Run Migration

```bash
php artisan migrate
```

Start Server

```bash
php artisan serve
```

Open Browser

```
http://127.0.0.1:8000
```
